# POBBOP segmented wordmark — Round 3

Three refinements derived from the supplied reference image's design language, not its pixel contours.

- A: four-point segmentation gives the O a reusable-system/crosshair rhythm.
- B: axis cuts are quieter and more premium.
- C: offset cuts add fashion-tech motion and a more ownable cadence.

These are concept masters using live SVG strokes for rapid comparison. After approval, the selected direction will be expanded to filled outlines for production.
