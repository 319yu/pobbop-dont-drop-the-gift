# POBBOP logo concepts — Round 1

## Brief

- Positioning: young, premium, fashion-led reusable creative gift packaging.
- Core cues: loop, fold, surprise, tactile construction, editorial restraint.
- Avoided clichés: literal gift boxes, bows, leaves, recycling arrows and generic stock-font initials.
- Primary use assumptions: packaging print/foil/emboss, social avatar, web header and small labels.

## Concepts

1. **Rhythm Wordmark** — custom geometric `POBBOP`; repeated round counters create a memorable spoken and visual beat.
2. **Orbit PBO** — `P`, `B` and `O` share one circular boundary, turning the name into a compact fashion-house monogram.
3. **Infinite Fold** — six folded faces orbit a clean centre, suggesting reuse and transformation without a literal recycling symbol.

All masters are black-first SVG artwork with outlined geometry and no live text, raster images, filters or masks.
